TEOTIHUACAN: CITY OF THE GODS — PRIVATE/UNLISTED PODCAST PACKAGE

WHAT THIS IS
This folder contains the 10 original MP3 episode files (copied byte-for-byte; not re-encoded), square podcast artwork, and an Apple-compatible RSS 2.0 feed template.

IMPORTANT: ONE FINAL EDIT IS REQUIRED AFTER YOU CHOOSE A HOST
The feed currently uses this placeholder base URL:
    https://YOUR-HOST.example/teotihuacan/

After uploading the whole folder, replace EVERY occurrence of that placeholder in feed.xml with the real public HTTPS URL of the uploaded folder, including the trailing slash. Example:
    https://yourname.example-host.app/teotihuacan/

The RSS feed URL you share will then be:
    <your base URL>/feed.xml

PRIVACY
This is UNLISTED, not access-controlled. The feed contains <itunes:block>yes</itunes:block>, and robots.txt asks web crawlers not to index the folder. It is not intended for submission to the public Apple Podcasts directory. Anyone who obtains the feed URL can still access it, so treat the URL as private.

APPLE PODCASTS TEST
On iPhone/iPad: Podcasts → Library → … → Follow a Show by URL, then paste the full HTTPS URL ending in feed.xml. Download all episodes before the site visit for offline playback.

HOST REQUIREMENTS
The host must serve HTTPS and allow public HTTP GET/HEAD requests and byte-range requests for the MP3 files. Do not password-protect the feed if you want the simplest Apple Podcasts URL-follow workflow.

FILES
- feed.xml: RSS feed; edit the placeholder URL after hosting.
- podcast-cover.jpg: 3000×3000 JPEG artwork.
- episodes/: 10 web-safe ASCII filenames copied directly from the uploaded MP3s.
- manifest.csv: episode order, durations, byte sizes, and SHA-256 checksums.
- robots.txt: asks search engines not to crawl the folder.
- .nojekyll: helps if you use GitHub Pages.
